# afterStellar2

Material de **¿Para qué Stellar?**, Argentina Builder Challenge (BAF × Stellar).

La pregunta que le hice a cada equipo la noche antes del Checkpoint #2: si le sacás Stellar a tu proyecto, ¿deja de funcionar? En varios casos la respuesta honesta era que no. Y esta clase existe para que esa pregunta se la hagan ustedes hoy, no el jurado mañana.

### Sobre la charla

No es una clase de fundamentos. Ya vieron eso. Esta es la de "che, pará un segundo antes de subir a Apex."

Un ejercicio simple: sacale Stellar mentalmente al proyecto. ¿Qué queda? Si queda exactamente lo mismo, todavía falta encontrar el por qué. Y después viene la parte incómoda de verdad: mostrar que la transacción de la demo pasó de una vez, no que el frontend dice que pasó.

Cierra con la agenda del Checkpoint #2: feature freeze, README en orden, y las fechas que quedan hasta el cierre de submission.
